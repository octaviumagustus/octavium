# Generador de Apersonamiento

Página HTML autónoma (sin servidor ni dependencias) que redacta un escrito de
apersonamiento y designación de abogado defensor ante Fiscalía o Juzgado.

## Uso
1. Abra `Generador_Apersonamiento.html` en cualquier navegador.
2. Complete el formulario de la izquierda; el escrito se genera a la derecha.
   Los datos pendientes aparecen resaltados en amarillo.
3. Exporte con **Imprimir / PDF**, **Descargar Word** o **Copiar**.

Los datos se guardan solo en el navegador (localStorage); nada se envía a internet.
